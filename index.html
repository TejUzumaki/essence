// Architecture Statement

We don't need servers. We need presence. DirectDrop treats the relay as a fallback, not a foundation. Peers discover each other through signed mDNS beacons on the local network, fall back to a STUN-assisted UDP holepunch, and only touch a TURN relay when both NAT types are symmetric.

The result: a 12ms median handshake on LAN, 80ms over WAN, zero persistent backend cost.

// The Honest Tradeoff

Symmetric NAT environments fail without TURN. We accept this. Engineering honesty: we'd rather fail visibly than pretend to be "serverless" while quietly renting a $400/mo relay cluster. The TURN relay is a 60-line coturn config.

// Design Brief

An open-world FPS on mobile is fundamentally a problem of budget. You have 16 milliseconds per frame, a thermal envelope that closes after 12 minutes of sustained load, and 4GB of RAM shared with the OS. Brainrot Adventure treats these constraints as the design.

The world is generated procedurally via deterministic noise, so storage is constant. The ECS batches render calls by material hash, dropping GPU draw count from 1,800 to 240.

// What It Doesn't Have

No microtransactions. No live-service backend. No accounts. The world is yours, offline, forever. The save file is a 4KB protobuf. If the player closes the app and reopens it in 2031, the world will still be there.

// Thesis

Willpower is a deprecated API. The dopamine economy has reverse-engineered human attention into a slot machine, and "discipline" cannot defeat a billion-dollar optimization pipeline. Digital Reset does not ask the user to resist — it inserts friction at the moment of compulsive action, just enough to make the loop visible.

The user reaches for Instagram. The PWA intercepts the intent. An 800ms delay. A prompt: "What are you avoiding?" The loop is broken.

// Data Privacy

Zero telemetry. Zero accounts. All trigger logs, streak counts, and reflection notes live in IndexedDB, on-device. The data never leaves the phone because the data cannot leave the phone.

PROJECT 04 / 04
मेरा管 / MERAKAN
Serverless P2P Video Streaming via WebRTC Gossip
StatusSOURCE OPEN
ProtocolWebRTC Gossip Mesh
Max Viewers~80 / Stream
Central ServerNone

// Premise

Twitch is a CDN pretending to be a community. MERAKAN (मेरा管 — "my pipe" / "my management") rejects the premise. A streamer should be able to broadcast from a phone, to a hundred phones, with no ingest server, no transcoding farm, no AWS bill. The mesh is the infrastructure.

Each viewer becomes a relay. The 3rd viewer receives chunks from the streamer and re-broadcasts to viewers 4 and 5. Total network capacity scales with audience size.

// Failure Modes

If a relay peer disconnects, downstream peers re-attach within 400ms via a backup peer list maintained by the gossip layer. The stream degrades — it does not die. The network topology self-heals.
