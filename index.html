// Architecture Statement

We don't need servers. We need presence. DirectDrop treats the relay as a fallback, not a foundation. Peers discover each other through signed mDNS beacons on the local network, fall back to a STUN-assisted UDP holepunch, and only touch a TURN relay when both NAT types are symmetric — which, statistically, is rare.

The result: a 12ms median handshake on LAN, 80ms over WAN, zero persistent backend cost.

// Why Hybrid Kotlin / WebRTC

Kotlin handles the signaling state machine natively — coroutine-based, garbage-tolerant, and capable of surviving Android's lifecycle butchery. WebRTC handles the media and data channels. The hybrid split means we don't ship a browser runtime to do browser work, and we don't ask a browser to do native work.

// The Honest Tradeoff

Symmetric NAT environments fail without TURN. We accept this. Engineering honesty: we'd rather fail visibly than pretend to be "serverless" while quietly renting a $400/mo relay cluster. The TURN relay is a 60-line coturn config, not a managed service.

// Design Brief

An open-world FPS on mobile is fundamentally a problem of budget. You have 16 milliseconds per frame, a thermal envelope that closes after 12 minutes of sustained load, and 4GB of RAM shared with the OS. Brainrot Adventure treats these constraints as the design — not as the obstacle.

The world is generated procedurally via deterministic noise, so storage is constant. The ECS batches render calls by material hash, dropping GPU draw count from 1,800 to 240 per frame.

// The Game Loop

The loop runs fixed-tick at 60Hz with a decoupled renderer at refresh rate. Entity updates parallelize across worker threads via a lock-free ring buffer; the main thread only orchestrates. Combat is hitbox-precise, not bbox-precise — because bbox combat on mobile feels like a spreadsheet.

// What It Doesn't Have

No microtransactions. No live-service backend. No accounts. The world is yours, offline, forever. The save file is a 4KB protobuf. If the player closes the app and reopens it in 2031, the world will still be there.

StatusSOURCE OPEN
PlatformPWA / Service Worker
BackendNone (IndexedDB)

// Thesis

Willpower is a deprecated API. The dopamine economy has reverse-engineered human attention into a slot machine, and "discipline" cannot defeat a billion-dollar optimization pipeline. Digital Reset does not ask the user to resist — it inserts friction at the moment of compulsive action, just enough to make the loop visible.

The user reaches for Instagram. The PWA intercepts the intent. An 800ms delay. A prompt: "What are you avoiding?" The loop is broken — not by force, but by visibility.

// How It Works

Installed as a PWA, Digital Reset registers itself as the default handler for high-friction URL patterns. When a registered domain is requested, the service worker returns a local intervention page instead — recording the trigger, surfacing the user's stated intent, and offering either a 5-minute delay or a hard cancel. The user opts in to every intervention.

// Data Privacy

Zero telemetry. Zero accounts. All trigger logs, streak counts, and reflection notes live in IndexedDB, on-device. The data never leaves the phone because the data cannot leave the phone — there is no upload path. The user is the only audience for their own behavior.

PROJECT 04 / 04
मेरा管 / MERAKAN
Serverless P2P Video Streaming via WebRTC Gossip
StatusSOURCE OPEN
ProtocolWebRTC Gossip Mesh
Max Viewers~80 / Stream
Central ServerNone

// Premise

Twitch is a CDN pretending to be a community. MERAKAN (मेरा管 — "my pipe" / "my management") rejects the premise. A streamer should be able to broadcast from a phone, to a hundred phones, with no ingest server, no transcoding farm, no AWS bill. The mesh is the infrastructure.

Each viewer becomes a relay. The 3rd viewer receives chunks from the streamer and re-broadcasts to viewers 4 and 5. The streamer's uplink stays constant; total network capacity scales with audience size.

// Gossip Topology

The mesh uses a structured gossip protocol — each peer maintains N active outbound connections and accepts M inbound. Chunk propagation follows a swarming pattern similar to BitTorrent's piece selection, with rarest-first prioritization. Playback is delayed by a 2-second buffer to allow mesh saturation before consumption.

// Failure Modes

If a relay peer disconnects, downstream peers re-attach within 400ms via a backup peer list maintained by the gossip layer. The stream degrades — it does not die. The network topology self-heals because every peer knows three alternative parents.

Engineering Manifesto // Four Operating Doctrines, Drag to Rearrange
These are not preferences. They are constraints I refuse to ship without.

Each window below is a draggable, resizable artifact. Treat them like terminal sessions — move them, scale them, read them in any order. The doctrines do not compete; they compose. On touch devices, pinch to zoom.

◉ anti-asset.md
// Anti-Asset Engineering

Don't build things that need to be maintained. Don't accumulate infrastructure. Ship the smallest possible artifact that holds its shape under load.

If a service exists, it must justify its memory, its CPU, and the 3am phone call it will eventually cause.

cat /doctrine/anti-asset --verify
◉ context_window.md
// Context-Window Hacking

Treat every prompt, every input, every keystroke as a constrained channel. Compress intent into structure.

The LLM is a co-processor, not a chat partner. Learn to speak in tokens, not sentences. Output is currency; spend it on signal.

tokens --budget 4096 --density max
◉ friction.md
// Friction Choreography

Friction is not the enemy. Default friction is.

Choreographed friction — the kind that slows the user before a destructive action, the kind that makes a "share" button cost one extra tap — is design. Choreograph it deliberately, never accidentally.

grep -r "default_friction" ./ux
◉ no_fake_data.md
// No Fake Data Policy

Mock data is technical debt with a smile. If you don't have the data, you don't have the feature.

Build the data path first. Then the feature is real, not a screenshot. The repo is not a portfolio piece — it is a witness statement.
